###### 📊 Job Analysis Dashboard | Power BI

## 🚀 Project Overview

The **Job Analysis Dashboard** is an interactive Power BI project designed to analyze job market trends, salary insights, skill demand, company hiring patterns, remote work opportunities, and geographic distribution of jobs.

This dashboard transforms raw job data into actionable insights, helping job seekers, recruiters, and analysts better understand the current employment landscape.

---

## 🎯 Objectives

* Analyze job postings across different locations and companies.
* Identify the most in-demand technical skills.
* Compare salaries across experience levels.
* Explore remote, hybrid, and on-site job opportunities.
* Visualize hiring trends using interactive dashboards.

## 📊 Key Insights

* Senior-level roles offer significantly higher salaries than entry-level positions.
* Python and Machine Learning remain the most demanded skills.
* Remote and hybrid opportunities continue to grow across AI & ML roles.
* Companies such as Google, NVIDIA, OpenAI, and Hugging Face show strong hiring activity.
* Geographic salary differences highlight opportunities across global markets.
